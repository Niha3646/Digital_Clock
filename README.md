# 🕒 Digital Clock
A simple and responsive Digital Clock built using HTML, CSS, and JavaScript. It displays the current time and date with a clean user interface and Light/Dark mode functionality.

## 📌 About the Project
Digital Clock is a simple and responsive web application developed using HTML, CSS, and JavaScript. It displays the current time and date in real time with an attractive user interface.

## ✨ Features
- Displays current time in real time.
- Shows current date and day.
- Attractive and user-friendly interface.
- Light Mode and Dark Mode.
- Responsive design.
- Automatically updates the time every second.

## 🛠️ Technologies Used
- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Clock functionality and theme switching.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enjoy your Digital Clock!
